      STEP 5 · BUSINESS INTERPRETATION

      Numbers are not recommendations until we explain them

      Do not say a type of content is best just because its total likes are higher. Check how many posts are in each group, and whether you have reach, impressions, or audience-size information.
      TEMPLATE, NOT A FINDING“In this dataset, category X has a higher median number of comments than category Y. The brand could test more posts in category X and compare results using a consistent metric.”

      Before you write it down

      • Did I compare medians as well as means?
      • Does each group have enough posts?
      • Am I claiming anything about reach, Pakistan, or paid ads? The data cannot support that.

      STEP 6 · DISCOVER THE NEED

      Make the data bigger, then measure

      Run the same simple analysis on repeated copies of your data. Repeated copies are a scaling experiment, not new real-world evidence. We are not trying to make Pandas fail.

      Load a dataset in step 2 first.

      Multipliers to run

      Pandas may handle millions of rows on some computers. There is no universal row count at which it “fails.” The need for Spark or distributed systems depends on data size, the operation, hardware, and service requirements. Spark is worth investigating when volume, processing time, or distributed storage needs justify it. It is not a requirement for a 2,000-row file.

      Reflect

      1. Which operation became slowest or most inconvenient as the rows grew?
      2. How much memory did the largest run use?
      3. Repeated rows are easier for a computer than varied real data. How might that change the result?
      4. What would change if the data were 100 GB, arrived every minute, or had to be shared by a whole team?

      STEP 7 · CONNECT TO ANALYTICS

      Classification, clustering, and regression, as a preview

      Classification

      Predict a category, such as high or low engagement, after defining a defensible label.

      Clustering

      Group posts with similar features. Scale numeric features first.

      Regression

      Predict a number such as likes, if the data supports it.

      Avoid data leakage. The label is built from likes, comments and shares, so those columns and anything made from them are never used as features. Models are scored on a held-out test set and compared with a baseline.

      Load a dataset in step 2 first.

      Exit question

      Which of these techniques would help answer your marketing question, and what evidence would you need?
