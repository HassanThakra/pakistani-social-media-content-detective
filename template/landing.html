Type a YouTube channel. See what its data does and doesn’t show.

Data Detective fetches a channel’s public videos, cleans them, explores them, and writes up each finding with its evidence and its limits beside it.

A channel link or @handle goes straight to the data. A brand name first shows channels to choose from, because search also returns reviews and fan pages.

This site has no YouTube API key set up yet, so live fetching is off. You can still explore the CSV workbench with the bundled dataset or your own file.

How the evidence is handled

Views are not reach
YouTube’s public data has views, not reach. Nothing here is called reach or an engagement rate on reach.
Hidden is not zero
If a creator hides likes or turns comments off, those videos are missing for that measure. They are never counted as 0.
Small groups are flagged
Every comparison shows how many videos are in each group. Channels with few videos get warnings, and the models switch off below 40.
The snapshot is recorded
Live data changes daily. Each report prints when it was fetched, what was typed, and the channel ID.

What you get

  1. Overview a one-screen summary and the top videos, linked back to YouTube.
  2. Cleaned data what was checked, what was fixed, and what was left blank on purpose.
  3. Explore charts and tables with group sizes next to every number.
  4. What it means Finding, Evidence, Action and Limitation for each pattern.
  5. Scaling the same analysis on repeated copies of the data, to see how Pandas behaves as it grows.
  6. Models classification, clustering and regression previews with a baseline and a leakage guard.
  7. Report a download and a link you can share for a few hours.
